# Rounak Samota — React Portfolio

A modern, animation-heavy senior frontend engineer portfolio built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
npm run preview
```

## Resume

Place your PDF at:

`public/Rounak_Samota_Resume.pdf`

The existing resume download button is already wired to that filename.

## Main technologies

- React 18
- Vite
- Framer Motion
- Lucide React
- Responsive CSS
- Dark / light mode
- Scroll reveal animations
- Reduced-motion accessibility support

## Content

The portfolio content is based on the supplied Rounak Samota resume. Project links are the URLs present in that resume.
